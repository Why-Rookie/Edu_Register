# 등록부 척척

엑셀에 명단만 적으면 한글(.hwpx) 등록부가 정렬·학교명 보정·쪽 나눔까지 자동으로 완성됩니다.

협의회·연수·회의 때마다 참석자 등록부를 한글에서 손으로 고쳐 만드느라 시간을 쓰셨나요?

엑셀에 명단을 적고 `등록부_만들기.bat`을 더블클릭하면, 정해진 양식 그대로 한글 등록부가 만들어집니다.

## 사용 방법

1. [Releases](../../releases)에서 `Edu_Register_V1.X.zip`을 받아 **압축을 풉니다.** (압축 파일 안에서 바로 실행하지 마세요)
2. `1. 엑셀 양식` 폴더의 빈 양식을 복사해 `2. 엑셀 넣는 곳` 폴더에 붙여넣고 이름을 바꿉니다.
3. 엑셀을 열어 노란 칸(제목·일시·장소)과 명단을 적고, 저장한 뒤 닫습니다.

4. `등록부_만들기.bat`을 더블클릭합니다.

5. `3. 완성된 한글 등록부` 폴더가 열리면 `.hwpx` 파일을 열어 확인하고 인쇄합니다.

## 주요 기능

- 소속을 **가나다순**으로 정렬
- 일반 등록부는 엑셀에 열 이름(예: 비고, 연락처)만 더 적으면 **한글 양식을 고치지 않아도 열이 추가**됨
- `OO초 / OO중 / OO고`를 `OO초등학교 / OO중학교 / OO고등학교`로 자동 변환
- 이름·소속이 길면 칸에 맞게 **장평(글자 폭)을 조절**해 한 줄로 표시
- 인원이 많으면 다음 쪽에 **같은 머리말과 표 머리글**을 넣어 이어서 생성 (일반 20명, 소통과 협업 25명 기준)
- 초·중·고가 섞여 있으면 "한 등록부에 모두 적을지, 학교급별로 나눌지" 선택
- 폴더에 엑셀 여러 개를 넣어 두면 **한 번에 모두 변환**
- 한셀로 저장한 xlsx도 지원
- **별도 설치 없음** — 휴대용 Python이 함께 들어 있습니다
- 모든 처리는 내 PC 안에서만 이루어지며 인터넷으로 데이터를 보내지 않습니다

## 지원하는 양식

| 양식 | 열 구성 | 쪽당 인원 |
| --- | --- | --- |
| 일반 등록부 | 연번 / 소속 / 직급 / 성명 / 서명 | 20명 |
| 공식 등록부(부서 내 소통과 협업) | 연번 / 날짜 / 기관명 / 부서명 / 직급 / 성명 / 서명 / 비고 | 25명 |


## 폴더 구성

```
Edu_Register_V1.1/
├ 등록부_만들기.bat      ← 더블클릭해서 실행
├ 사용설명서.txt
├ 1. 엑셀 양식/          빈 엑셀 양식 (복사해서 사용)
├ 2. 엑셀 넣는 곳/       내용을 적은 엑셀을 여기에 넣음
├ 3. 완성된 한글 등록부/  만들어진 .hwpx가 저장됨
└ _program/              프로그램 본체 (건드리지 않음)
```

## 요구 사항

- Windows PC
- 만들어진 `.hwpx`를 열 수 있는 한글(한컴오피스) 또는 한글 뷰어
- 엑셀 또는 한셀 (`.xlsx`로 저장)

## 자주 생기는 문제

- **"파일이 열려 있습니다"** → 엑셀 또는 한글에서 해당 파일을 닫고 다시 실행하세요.
- **같은 이름으로 다시 만들면 덮어씁니다** → 한글에서 직접 고친 파일은 다른 이름으로 저장해 두세요.
- **"변환할 엑셀 파일이 없습니다"** → `2. 엑셀 넣는 곳`에 `.xlsx` 파일이 있는지 확인하세요. `.xls`, `.csv`는 `.xlsx`로 다시 저장해야 합니다.
- 결과는 반드시 한글에서 열어 눈으로 확인한 뒤 사용해 주세요.
- 일부 백신이 `_program\python\python.exe`를 경고할 수 있습니다. 이 폴더는 공식 휴대용 Python이며, 지우거나 옮기면 실행되지 않습니다.

## 개발 메모

- 엑셀(.xlsx)을 직접 읽어 한글(.hwpx, 압축된 XML) 양식 파일에 내용을 채워 넣는 방식입니다. 한글·엑셀 프로그램이나 외부 라이브러리가 필요 없습니다.
- 양식 파일(`_program/양식*.hwpx`)은 글자 내용이 아니라 **구조(표 위치·열 수)**로 찾아 채우므로, 양식 안의 문구를 지워도 동작합니다. 단, 맨 위 제목 표, `일시`/`장소`(공식 양식은 `참석자`) 줄, 명단 표(일반 5열, 공식 8열)는 남겨 두어야 합니다.
- 글자 폭 조절은 글꼴 폭 정보(`_program/metrics.py`)로 계산합니다.

## 라이선스 및 참고

- 프로그램 코드: 저장소 소유자가 정한 라이선스를 따릅니다. (`LICENSE` 파일 참조)
- `_program/python/`: [Python Software Foundation 라이선스](https://docs.python.org/3/license.html)의 공식 휴대용(embeddable) Python 3.14이며, 폴더 안 `LICENSE.txt`를 함께 배포합니다.
- 양식이 사용하는 글꼴(한컴 윤고딕, 휴먼명조)은 파일에 포함되어 있지 않고 이름만 지정되어 있습니다. 해당 글꼴이 없는 PC에서는 다른 글꼴로 대체됩니다.
- 예시 이미지의 이름은 모두 가상의 이름입니다.
